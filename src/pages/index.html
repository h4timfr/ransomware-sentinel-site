Ransomware Sentinel

Local behavioural ransomware detection for Windows.

It watches the folders you choose, scores ransomware-like file activity against five published rules, and records every alert, incident and response in a tamper-evident log. Nothing leaves your PC, and nothing is decided for you.

01 — What it watches

The folders you choose. Nothing else.

Setup proposes the folders where your own files live, resolved through the Windows Known Folder API, so a Documents folder redirected to OneDrive or another drive is found where it really is.

Proposed
Desktop, Documents, Downloads, Pictures, Videos, Music. Untick any of them, or add your own.
Off by default
OneDrive. Its sync client renames files in bursts that look like an attack. Switch it on if you want it watched.
Never proposed
Drive roots, the Windows folder and Program Files. Adding one by hand shows a warning first.
Initial scan
Lists existing files and checks their names for encrypted-looking extensions. It never opens or changes a file, and monitoring is already running while it scans.
Coverage
Each folder reports Watched, Covered, Missing or No access. Junctions are not followed. A folder deleted and recreated is watched again, and the gap is reported.
Runs
While Sentinel is open. It does not start with Windows on its own; it can start protection each time you open it.

02 — How it decides

Five rules, one bounded score, a reason for every point.

Detection is behavioural and deterministic: it does not look for known malware. Within a sliding 30-second window, Sentinel counts what is happening to files in protected folders. Each rule that crosses its threshold adds its points; the weights sum to 100.

  • Rapid file modification50 changes in the window+25
  • Mass file rename20 renames+25
  • Suspicious extensiona rename to a listed extension such as .locked; 10 changes to unfamiliar extensions; or a copy to a new extension followed by deletion of the original+20
  • Mass file creation50 new files+15
  • High event concentration75 events of any kind+15
LOW1–29

Recorded with the event. Nothing is raised.

MEDIUM30–59

Events are marked for review.

HIGH60–79

An alert is raised. Related alerts become one incident.

CRITICAL80–100

As HIGH, and the posture changes to CRITICAL THREAT.

At no level does Sentinel block, delete or end anything by itself. Thresholds can be adjusted in Settings within fixed bounds.

03 — What you see

Every alert arrives with its evidence.

An incident groups the alerts from one episode. It shows the rules and points behind the score, what happened to each file, following renames as one file, and a timeline of every action taken.

Attribution
Windows file events do not say which program made a change. Sentinel reports UNKNOWN rather than guessing; a program it does name is a lead, not proof.
Forensic record
Incidents, trust decisions, quarantine actions and configuration are committed to an HMAC-SHA256 chain, verified at start-up and on demand. Rolled-back or edited records are reported.
Exports
Incident reports and diagnostics are files you choose to save. They contain paths, never file contents or keys.

04 — What you can do

You decide the response. Sentinel records it.

Triage
Acknowledge, investigate, resolve or dismiss. Every action is confirmed and written to the incident's audit trail.
Contain
Quarantine moves an executable that an incident names into Sentinel's store under an inert name. Containment, not isolation.
Restore
Verified byte-for-byte against the recorded hash, and never written over a file already at the destination.
Recover
Sentinel cannot decrypt files. Recovery readiness checks that a recent, independent copy appears to exist in your backup folders.
Verify
Diagnostics shows monitoring, telemetry, database and audit-chain health. Events lost under load are counted and shown.
Rehearse
The Safe Demo renames inert text files in Sentinel's own workspace, so the real pipeline opens a real incident. It encrypts nothing.

05 — Boundaries

Know what Sentinel does — and what it doesn't.

It does

  • Watch the folders you choose, in user mode, while it is open
  • Score ransomware-like activity and explain every point
  • Group alerts into incidents and record every response in a tamper-evident log
  • Report its own health, including events it could not analyse
  • Keep everything on your PC: no account and no network connections

It does not

  • Replace Microsoft Defender or antivirus. Keep them on.
  • Block programs or file changes. It detects and records; you act.
  • Decrypt or recover files. Keep tested backups.
  • See below user mode or outside your folders. No kernel driver, no ETW.
  • Guarantee that every ransomware attack is detected. Slow or in-place encryption can stay below an alert.
