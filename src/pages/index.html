Features

What Ransomware Sentinel does

Automatic protection, set up in a minute

Sentinel finds your Desktop, Documents, Downloads, Pictures, Videos and Music through Windows itself, so a Documents folder that has been moved to OneDrive or another drive is found where it really is.

  • OneDrive is detected and offered, but off by default: its sync client creates and renames files in bursts that can look like an attack.
  • Starting protection turns on continuous monitoring and runs a quick initial scan of file names. Listing your files is never mistaken for ransomware.
  • Optionally, protection starts by itself each time you open Sentinel.

Behaviour-based detection with a score you can read

Sentinel doesn't rely on recognising known ransomware files. It looks at what is happening to your files over a 30-second window:

  • Rapid file modification 50 changes · 25 pts
  • Mass file renaming 20 renames · 25 pts
  • Renames to encrypted-looking extensions any · 20 pts
  • Mass file creation 50 new files · 15 pts
  • High overall event concentration 75 events · 15 pts
LOW1–29
MEDIUM30–59
HIGH60–79
CRITICAL80–100

A HIGH score raises an alert. Related alerts are grouped into one incident per episode. Thresholds are adjustable in Settings.

Investigate and respond, with a record of every step

An incident shows the rules and points behind its score, what happened to each file (following renames as one file), and a timeline of every action taken.

  • Acknowledge, mark as investigating, resolve or dismiss. Each action is confirmed and recorded.
  • When an incident names a program file, Sentinel can quarantine it. Often it can't name one (see limits), and it says so rather than guessing.
  • Security records go into a tamper-evident (HMAC-SHA256 chained) audit log, checked at start-up and on demand.

A Safe Demo you can run any time

Curious what an alert looks like, or want to show someone? The Demo Center creates, edits and renames harmless text files in its own isolated folder and lets the real product detect them.

  • It encrypts nothing, touches none of your files, ends no process and changes no system setting.
  • Each step turns green only when the product has actually done it.
  • Reset removes the demo files; the records are kept.

Checks itself

Diagnostics show whether monitoring, the database and the audit chain are healthy, so "protected" is something you can verify.

Recovery readiness

Sentinel can't recover encrypted files. A backup can. Point Sentinel at your backup folder and it checks that a recent copy appears to exist.

Guided all the way

A setup wizard, a guided tour of the real controls, a "next step" on the dashboard and short explanations wherever a term needs one.

What it is, and what it isn't

A focused tool, stated plainly

Ransomware Sentinel is one extra layer that watches your personal folders and explains what it sees. It is not a complete security suite, and it does not pretend to be.

It does

  • Watch the folders you choose, while Sentinel is open
  • Recognise ransomware-like behaviour and explain the score
  • Group related alerts into one incident and record every response
  • Keep everything on your computer, with no account and no internet connection needed
  • Check whether a recent backup appears to exist

It does not

  • Replace Microsoft Defender or antivirus. Keep them on.
  • Stop programs or block file changes. It detects and records; you act.
  • Decrypt or recover files. Keep backups.
  • Watch folders you haven't chosen, or run before you open it. It doesn't start with Windows by itself.
  • Usually know which program made a change. File events don't say, and Sentinel doesn't guess.
  • Guarantee that every ransomware attack is detected.

The full list of limitations is in the documentation and the technical report.

Questions

Common questions

Is Ransomware Sentinel free?

Yes. There is no price, no subscription and no account.

Does it upload my files?

No. Sentinel has no internet features at all: it does not upload files, scan results or usage data. Everything it records stays in your user profile on your computer.

Does it replace Windows Defender?

No. Sentinel is not antivirus. Keep Microsoft Defender (or your antivirus) turned on and keep backups; Sentinel adds a layer that watches your personal folders for ransomware-like behaviour.

Why might Windows show a warning when I run the installer?

The installer is not code-signed yet, and it is a new download that Windows has not seen often. Windows SmartScreen may therefore say it "protected your PC". The download page explains what the warning means and how to check the file is the genuine one.
