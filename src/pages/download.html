Installing

Install in five steps

  1. Download the installer

    Press Download for Windows above. Your browser saves {{installerFile}}, usually in your Downloads folder.

  2. Open it

    Open the file from your browser's downloads list or from the Downloads folder. Windows may show a warning first; see why, and what to do.

  3. Choose who it is for

    Setup asks whether to install for all users (recommended; Windows asks for permission to make changes) or just for you (no administrator rights needed). Then read the short "Before you install" page.

  4. Finish setup

    Keep the suggested folder, choose whether you want a desktop shortcut, and press Install. Leave Open Ransomware Sentinel now ticked and press Finish.

  5. Choose your folders

    Sentinel opens with a four-step setup: it explains what it does, proposes your folders, runs a quick scan and starts protection. The documentation walks through every screen.

Sentinel protects while it is open. It does not start with Windows by itself. Open it from the Start menu (or the desktop shortcut) when you start your computer; you can let it start protection automatically every time it opens.

If Windows shows a warning

The installer is not code-signed yet: it does not carry a certificate identifying its publisher, and as a new download Windows has not seen it often. Because of that you may see one or more of these:

  • Your browser may say the file "isn't commonly downloaded".
  • Microsoft Defender SmartScreen may say "Windows protected your PC" and, under More info, list the publisher as Unknown publisher.
  • When installing for all users, Windows asks whether to allow an app from an unknown publisher to make changes.

These warnings are Windows being careful with software it can't yet vouch for, and they are worth taking seriously. Before you continue, make sure that:

  • you downloaded the file from this page yourself, and
  • the file is named {{installerFile}}{{#if sha256}} and, if you want to be certain, its SHA-256 checksum matches the one above{{/if}}.

If both are true and you want to install, SmartScreen's More info link shows a Run anyway button. If you are unsure, don't run it, and ask someone you trust to check it with you.

Never turn off Microsoft Defender, SmartScreen or your antivirus to install Ransomware Sentinel (or anything else). Nothing on this site asks you to.

Check the file (optional)

A SHA-256 checksum is a fingerprint of the file. If even one byte differs, the fingerprint is completely different. To compare it, open Windows PowerShell from the Start menu and run:

Get-FileHash "$env:USERPROFILE\Downloads\{{installerFile}}" -Algorithm SHA256

The Hash it prints should match the checksum {{#if sha256}}shown above{{else}}published with the release{{/if}} (capital and small letters don't matter). The checksum is also published as {{installerFile}}.sha256 with the release.

Other options: certutil -hashfile {{installerFile}} SHA256 in Command Prompt, or sha256sum on Linux and macOS.

Uninstalling

  1. Close Ransomware Sentinel.
  2. Open Settings → Apps → Installed apps (on Windows 10: Settings → Apps → Apps & features).
  3. Find Ransomware Sentinel, choose Uninstall and confirm.

Uninstalling removes the program. Your Sentinel records (incident history, audit log, settings and any quarantined files) are deliberately kept in %LOCALAPPDATA%\RansomwareSentinel; delete that folder yourself if you no longer need them. Reinstalling later picks them up again.

Updating

Sentinel does not update itself or check for updates (it never connects to the internet). To update, download the newer installer from this page and run it: it replaces the program and keeps your settings and records.
