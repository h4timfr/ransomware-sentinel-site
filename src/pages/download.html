Before you run it

Windows may show a SmartScreen warning

Because the current installer is not digitally signed, Microsoft Defender SmartScreen may show an "unrecognized app" warning ("Windows protected your PC", publisher Unknown publisher). SmartScreen shows this for software whose publisher identity and download reputation it cannot yet establish. It is not a malware verdict, and it is worth taking seriously.

Before you continue, check two things: you downloaded {{installerFile}} from this page yourself, and its SHA-256 matches the one published here. If both are true, More info → Run anyway continues. If you are unsure, don't run it.

Never turn off Microsoft Defender, SmartScreen or your antivirus to install Ransomware Sentinel, or anything else. Nothing on this site asks you to.

Verify

Check the file's SHA-256

A SHA-256 checksum is a fingerprint of the file: change one byte and it is completely different. In Windows PowerShell, run:

cd "$HOME\Downloads"
Get-FileHash .\{{installerFile}} -Algorithm SHA256

The Hash it prints must match {{#if sha256}}the checksum above{{else}}the checksum published with the release{{/if}}; capitalisation does not matter. From the same folder in Command Prompt, certutil -hashfile {{installerFile}} SHA256 gives the same value.

Install

Four steps

  1. Run the installer

    Open {{installerFile}} from your browser's downloads. If SmartScreen warns, see above.

  2. Choose who it is for

    All users (Windows asks for permission) or just you (no administrator rights). Read the short "Before you install" page.

  3. Install and open

    Keep the suggested folder, choose whether you want a desktop shortcut, and leave Open Ransomware Sentinel now ticked.

  4. Choose your folders

    The first-run setup proposes your folders, runs a quick scan and starts protection. The documentation covers every screen.

Afterwards

Updating and uninstalling

Updating. Run a newer installer from this page. It replaces the program and keeps your settings and records.

Uninstalling. Settings → Apps → Installed apps → Ransomware Sentinel → Uninstall. Your records in %LOCALAPPDATA%\RansomwareSentinel are kept on purpose; delete that folder yourself if you no longer need them.
