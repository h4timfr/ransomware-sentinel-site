Before you run it

Windows may show a SmartScreen warning

The installer is not code-signed yet, so Microsoft Defender SmartScreen may show an "unrecognized app" warning ("Windows protected your PC", publisher Unknown publisher). SmartScreen shows this for software whose publisher it cannot identify and whose download reputation it cannot yet establish. It is not a malware verdict, and it is worth taking seriously.

Before you continue, check two things: you downloaded {{installerFile}} from this page yourself, and its SHA-256 matches the one above. If both are true, More info → Run anyway continues. If you are unsure, don't run it.

Never turn off Microsoft Defender, SmartScreen or your antivirus to install Ransomware Sentinel, or anything else. Nothing on this site asks you to.

Install

Four steps

  1. Run the installer

    Open {{installerFile}} from your browser's downloads. If SmartScreen warns, see above.

  2. Choose who it is for

    All users (Windows asks for administrator permission) or just you (no administrator rights needed).

  3. Install and open

    Keep the suggested folder, choose whether you want a desktop shortcut, and leave Open Ransomware Sentinel now ticked.

  4. Choose your folders

    The first-run setup proposes your folders, runs a quick scan and starts protection. The documentation covers every screen.

Afterwards

Updating and uninstalling

Updates
Sentinel makes no network connections, so it never checks for updates. Run a newer installer from this page; it replaces the program and keeps your settings and records.
Uninstall
Settings → Apps → Installed apps → Ransomware Sentinel → Uninstall. Your records in %LOCALAPPDATA%\RansomwareSentinel are kept on purpose; delete that folder yourself if you no longer need them.
Source
The application's source code is not public. This website and the installer releases are public in the GitHub repository.
