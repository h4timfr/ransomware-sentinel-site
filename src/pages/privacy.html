Privacy and terms, in plain words

The application

  • No account. Sentinel has no sign-up, sign-in or user database.
  • No internet connection. The application contains no network code: it does not upload your files, file names, scan results, incidents or usage data, it has no telemetry, and it does not check for updates.
  • What it stores, and where. Its database (events, alerts, incidents, the actions you took), audit log, settings, logs and any quarantined files are kept on your computer in %LOCALAPPDATA%\RansomwareSentinel, readable by your Windows account.
  • What it looks at. File-system activity in the folders you choose (changes, renames, new files and their names), and a list of running processes to suggest which program might be involved. It does not read the contents of your files.
  • Sharing is up to you. Nothing leaves your computer unless you export it yourself (for example Export Diagnostics or Export Report). Exports contain file paths, which can include your Windows user name; check them before sending them to anyone.
  • Uninstalling removes the program but keeps that data folder; delete it yourself if you want it gone.

This website

  • No cookies, analytics, advertising, trackers, session recording or fingerprinting.
  • No third-party scripts or fonts: every file the pages use comes from this site.
  • The site is a set of static pages hosted on GitHub Pages, and the installer is downloaded from GitHub. Like any web host, GitHub receives your IP address and browser details when you visit or download; see the GitHub General Privacy Statement.

License

Ransomware Sentinel is offered free of charge. Its source code is not public, and no open-source license has been published for it. If a license is published in the future, it will be stated here and in the release notes.

The application uses open-source components, including Python, Qt for Python (PySide6, LGPLv3), watchdog and psutil. Each remains under its own license; their notices and license texts are installed with the program as THIRD-PARTY-NOTICES.txt in its folder. The Qt libraries are included as separate, unmodified files and can be replaced.

Disclaimer

Ransomware Sentinel is security software that detects ransomware-like behaviour in the folders you choose while it is running. It is not antivirus, it does not block programs or file changes, and it cannot decrypt or recover files. No security product can guarantee that every attack is detected or prevented, and this one does not claim to.

Use it alongside Microsoft Defender (or another antivirus), Windows updates and regular, tested backups of the files that matter to you. It is provided as is, without warranty of any kind.

Contact and security reports

There is no dedicated support or security contact address. To report a problem, open an issue in the public GitHub repository. For a security vulnerability, open an issue asking for a private way to share the details instead of posting them publicly. Please never attach personal files.
