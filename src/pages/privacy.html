Privacy

Ransomware Sentinel works entirely on your computer. Here is exactly what it stores, and what this website does and does not collect.

The application

Everything stays on your PC

Network
None. The application makes no network connections: no uploads, no telemetry, no account and no update checks.
What it observes
File activity in the folders you protect (creations, changes, renames, deletions and file names) and a list of running processes for context. It does not read the contents of your files.
What it stores
Its database, audit chain, logs, settings and any quarantined files, in %LOCALAPPDATA%\RansomwareSentinel, readable by your Windows account. Uninstalling keeps this folder until you delete it.
Exports
Nothing is shared unless you save an export (diagnostics or an incident report) and send it yourself. Exports contain file paths, which can include your Windows user name; read them before sharing.

This website

No cookies, analytics or trackers

Collected by this site
Nothing. No cookies, analytics, advertising, session recording or fingerprinting, and no third-party scripts or fonts: every file the pages load comes from this site.
Hosting
The pages are served by GitHub Pages and the installer is downloaded from GitHub. Like any web host, GitHub receives your IP address and browser details; see the GitHub General Privacy Statement.

License and disclaimer

Ransomware Sentinel is offered free of charge. Its source code is not public and no open-source license has been published for it; if one is, it will be stated here and in the release notes. It includes open-source components (Python, Qt for Python under LGPLv3, watchdog and psutil), each under its own license; their notices are installed with the program as THIRD-PARTY-NOTICES.txt.

Sentinel detects ransomware-like behaviour in the folders you choose while it is running. It is not antivirus, it does not block programs or file changes, and it cannot decrypt or recover files. No security product can guarantee that every attack is detected or prevented, and this one does not claim to. It is provided as is, without warranty of any kind. Use it alongside Microsoft Defender, Windows updates and tested backups.

There is no support or security contact address. Report problems through GitHub issues; for a vulnerability, open an issue asking for a private channel rather than posting details.
