Basics

What does Sentinel monitor?

File and folder creation, modification, deletion and renames inside the folders you protect, plus a periodic list of running processes for context. During the initial scan it reads file names. It never opens or reads the contents of your files. What it watches

Does it replace Microsoft Defender?

No. Sentinel is not antivirus: it does not scan programs for malware and does not block anything. Keep Microsoft Defender (or your antivirus) on and keep backups; Sentinel is an extra layer that explains ransomware-like behaviour in your folders.

Is it free? Do I need an account?

It is free, and there is no account, subscription or sign-in.

Privacy and data

Does anything leave my computer? Does it work offline?

Nothing leaves your computer. The application makes no network connections: no uploads, no telemetry, no update checks, and it works fully offline. Files leave only if you save an export and send it yourself. Privacy

Where is my data stored?

In %LOCALAPPDATA%\RansomwareSentinel in your user profile: the database, the audit chain, logs, settings and the quarantine store. Uninstalling keeps it until you delete it. Data storage

Detection and response

What happens when suspicious activity is detected?

At a risk score of 60 or more Sentinel raises an alert, groups it into an incident and shows it on the dashboard's Next step. The incident lists the rules that fired and what happened to each file. You decide the response, and Sentinel records it. Alerts and incidents

Does it automatically delete, block or quarantine files?

No. Sentinel never deletes, blocks or ends anything by itself. Quarantine happens only when you choose it, and only for a program file an incident names; it is containment, not isolation.

Will it tell me which program caused it?

Usually not. Windows file events do not say which program made a change, so attribution is normally UNKNOWN, and Sentinel says so rather than guessing. A program it does name is a lead, not proof.

Can it stop every ransomware attack?

No, and no honest tool can promise that. Detection is rate-based: files encrypted in place without renaming, or slowly enough that no 30-second window looks unusual, can stay below an alert. That is why it belongs alongside antivirus and backups. Limitations

What is the Safe Demo?

A built-in demonstration that creates and renames inert text files in Sentinel's own workspace, so you can watch a real detection, alert and incident. It encrypts nothing and touches none of your files. Safe Demo

Does it work with OneDrive?

OneDrive is detected and listed but off by default, because its sync client renames files in bursts that look like an attack. Folders Windows has redirected into OneDrive, such as Documents, are found and watched where they are.

Does it run all the time?

Only while it is open. It does not start with Windows on its own; open it when you start your computer and it can start protection automatically. If it is closed or ends, nothing is watched until you open it again.

Installing

Why does Windows SmartScreen warn me? Is the installer signed?

The installer is not code-signed yet, so SmartScreen cannot confirm its publisher and may show an "unrecognized app" warning. Make sure you downloaded it from this site and that its SHA-256 matches the published value. Never switch off Defender or SmartScreen to install anything. What to check

Do I need administrator rights?

Only to install for all users. You can install just for yourself without them, and running Sentinel never needs them.

How do I update or uninstall?

To update, run the newer installer; your settings and records are kept. To uninstall, use Settings → Apps → Installed apps. Details

The project

Can I inspect the source?

Not at present: the application's source code is not public and no open-source license has been published. This website and the installer releases are public on GitHub, and the technical reference describes how Sentinel works.

Who makes it?

Ransomware Sentinel is an independent academic security project, not a company product. It has no certifications and no commercial support.

How do I report a problem or a vulnerability?

Open an issue in the GitHub repository. Don't attach personal files, and remember a diagnostics export contains file paths. For a vulnerability, open an issue asking for a private way to share the details instead of posting them.
