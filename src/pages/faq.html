FAQ

Frequently asked questions

Short, straight answers. For step-by-step help, see the documentation.

The basics

Is Ransomware Sentinel free?

Yes. There is no price, no subscription, no trial period and no account.

Does it require an account?

No. You install it and use it. There is nothing to sign up for or sign in to.

What does it actually do?

It watches the folders you choose for the behaviour ransomware leaves behind (bursts of changes, mass renaming, files renamed to extensions such as .locked), scores that activity from 0 to 100, explains every point, groups related alerts into an incident, and helps you investigate and respond. It also checks itself and keeps a tamper-evident record of what it saw and what you did.

Does it replace Windows Defender or my antivirus?

No. Ransomware Sentinel is not antivirus: it does not scan programs for malware, and it does not stop programs or block file changes. Keep Microsoft Defender (or your antivirus) turned on and keep backups. Sentinel adds a focused layer that watches your personal folders and explains ransomware-like behaviour.

Do I still need backups?

Yes. Sentinel cannot decrypt or recover files. A backup is what gets your files back. Sentinel's Recovery page can check that a recent backup appears to exist in the folder your backup tool writes to.

Privacy

Does it upload my files?

No. Sentinel has no internet features at all. It does not upload files, file names, scan results or usage data, and it has no telemetry. Its records stay in %LOCALAPPDATA%\RansomwareSentinel in your user profile.

Does it work offline?

Yes, completely. Detection runs on your computer and needs no connection. (It also means Sentinel does not update itself: newer versions are published on the download page.)

Does it read my documents?

No. It watches file-system activity (changes, renames, new files) in your protected folders and checks file names during the initial scan. It does not open or read the contents of your files.

Protection

What folders does it protect?

By default Desktop, Documents, Downloads, Pictures, Videos and Music, found through Windows, so redirected folders are found where they really are. You can untick any of them and add other folders. Folders you haven't chosen are not watched.

Does it work with OneDrive?

Sentinel detects OneDrive and lists it, but leaves it off by default: the OneDrive sync client creates and renames files in bursts that can look like ransomware and raise alerts. You can switch it on in Protected Locations. If your Documents or Desktop folder has been moved into OneDrive, Sentinel finds and protects it where it is.

Does it run all the time?

It protects while it is open. Closing the window stops protection, and Sentinel does not start with Windows by itself. Open it from the Start menu when you start your computer; with Start protection automatically when Sentinel opens ticked, it starts watching straight away.

What happens during the initial scan?

Each time protection starts, Sentinel lists the files already in your protected folders and flags names with encrypted-looking extensions. It never opens or changes a file. Continuous monitoring starts first, so your folders are watched while the scan runs. You can skip the scan; monitoring keeps running.

What happens if suspicious activity is detected?

Sentinel raises an alert (from a risk score of 60), opens an incident and shows it on the dashboard's Next step. The incident explains which rules fired and what happened to each file. Sentinel does not stop programs itself: you decide what to do, and it records each step.

If you weren't doing something that changes many files at once, disconnect from the network, run a full scan with your antivirus and check your backups. The documentation has the details.

Will it tell me which program caused it?

Usually not. Windows file events don't say which program made a change, so attribution is normally UNKNOWN, and Sentinel says so rather than guessing. When it does name a candidate program, that is a lead, not proof.

Can it stop every ransomware attack?

No, and no honest tool can promise that. Sentinel detects ransomware-like behaviour in the folders it watches while it is open. It can't guarantee every attack is detected, and it doesn't block anything itself. That is why it belongs alongside antivirus and backups.

How can I see it working without real ransomware?

Use the Demo Center. It creates and renames harmless text files in its own isolated folder so you can watch a real detection, alert and incident. It encrypts nothing and touches none of your files.

Installing

What Windows versions are supported?

{{windows}}. It has been tested on {{testedOn}}. Windows on Arm PCs have not been tested.

What if Windows SmartScreen shows a warning?

The installer isn't code-signed yet and is a new download, so SmartScreen may say "Windows protected your PC". Check that you downloaded it from this site and, if you like, that its SHA-256 checksum matches. The download page explains the options. Never switch off Defender or SmartScreen to install anything.

Do I need administrator rights?

Only to install for all users (the recommended option). You can choose to install just for yourself without administrator rights. Running Sentinel never needs them.

Do I need Python or any other software?

No. The installer contains everything Sentinel needs.

Can I uninstall it?

Yes, like any Windows app: Settings → Apps → Installed apps → Ransomware Sentinel → Uninstall. Your Sentinel records are kept in %LOCALAPPDATA%\RansomwareSentinel in case you need them; delete that folder if you don't. (If you reinstall later, Sentinel reports the deleted history once; confirm it in Diagnostics.)

How do I update?

Download the newer installer from the download page and run it. It replaces the program and keeps your settings and records.

About the project

Is the source code available?

Not at the moment. The application's source code is kept in a private repository, and no open-source license has been published. This website and the installer releases are public on GitHub. The technical report describes how Sentinel works in detail.

Who makes it?

Ransomware Sentinel is an independent academic cybersecurity project. It is not a company product, and it has no certifications or commercial support.

How do I report a problem?

Open an issue in the project's public GitHub repository. Please don't include personal files, and remember that a diagnostics export contains file paths. To report a security vulnerability, open an issue asking for a private way to share the details, rather than posting them publicly.
