The product

What is Ransomware Sentinel?

A free Windows application that watches the folders you choose for ransomware-like file activity, explains a risk score for it, and records incidents on your PC. It detects and records; you decide what to do. There is no account or subscription.

Which systems are supported? Is there a macOS version?

{{windows}}, tested on {{testedOn}}. A macOS version is planned but not available: the current release relies on Windows-specific system facilities. There is no Linux version, and Windows on Arm has not been tested.

Does it replace antivirus?

No. It does not scan programs for malware or block anything. Keep Microsoft Defender (or your antivirus) on and keep backups; Sentinel adds behavioural detection and an explained record on top.

Detection

Which folders can it watch?

Setup proposes Desktop, Documents, Downloads, Pictures, Videos and Music, and you can add any folder. OneDrive is listed but off by default, because its sync client renames files in bursts that look like an attack. Choosing folders

How does risk scoring work?

Five behavioural signals are counted over a sliding 30-second window. Each one over its threshold adds fixed points (25, 25, 20, 15 or 15), and the total is a 0–100 score: LOW, MEDIUM from 30, HIGH from 60, CRITICAL from 80. The signals and thresholds

What triggers CRITICAL, and what happens then?

A score of 80 or more, which takes at least four signals at once with the default thresholds. The security posture becomes CRITICAL THREAT while the incident is open. Sentinel still does not block, quarantine or delete anything by itself; the response is yours. Responding

Will it tell me which program caused it?

Usually not. Windows file events do not say which program made a change, so attribution is normally UNKNOWN, and Sentinel says so rather than guessing. A program it does name is a lead, not proof.

Is the Safe Demo real ransomware?

No. It creates and renames inert text files in Sentinel's own workspace, encrypts nothing and touches none of your files. Everything after those files is the real product: real detection, a real alert and a real incident. Safe Demo

What are its main limitations?

It watches only your protected folders, only while it is open, in user mode. Files encrypted in place without renaming, or slowly, can stay below an alert, so it cannot promise to catch every attack. It cannot decrypt files. Every limitation

Privacy

Does it upload files or use cloud services?

No. The application makes no network connections: no uploads, no telemetry, no cloud lookups and no update checks, and it works fully offline. Files leave your PC only if you save an export and send it yourself. Privacy

Where is my data stored?

In %LOCALAPPDATA%\RansomwareSentinel in your user profile. Uninstalling keeps it until you delete it. Data storage

Installing

Why does Windows SmartScreen warn me?

The installer is not code-signed yet, so SmartScreen cannot identify its publisher and may show an "unrecognized app" warning. That is not a malware verdict. Continue only if you downloaded it from this site and its checksum matches. Never switch off Defender or SmartScreen. What to check

How can I verify the installer?

Compare its SHA-256 with the value on the download page, using Get-FileHash in PowerShell or certutil in Command Prompt. Verify the download

Do I need administrator rights? How do I uninstall?

Only to install for all users; you can install just for yourself without them, and running Sentinel never needs them. Uninstall from Settings → Apps → Installed apps. Updating and uninstalling

The project

Who makes it, and is the source available?

Ransomware Sentinel is an independent academic security project, not a company product, with no certifications or commercial support. The application's source code is not public and no open-source license has been published. This website and the installer releases are public on GitHub.

How do I report a problem or a vulnerability?

Open an issue in the GitHub repository. Don't attach personal files; a diagnostics export contains file paths. For a vulnerability, open an issue asking for a private way to share the details instead of posting them.
