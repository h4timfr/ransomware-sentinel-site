## Ransomware Sentinel 1.3.0

**The first version available as a Windows installer.** Download
`RansomwareSentinel-Setup.exe`, run it, and Sentinel opens with a short setup
that helps you choose the folders to protect. No Python, command line or
account needed.

- Works on Windows 10 (version 1809 or later) and Windows 11, 64-bit. Tested on Windows 11.
- Free. Runs entirely on your computer; it has no internet features.
- **Not code-signed yet**, so Windows SmartScreen may warn about an unknown
  publisher. Download it only from the [official download page](https://h4timfr.github.io/ransomware-sentinel-site/download/),
  and compare its SHA-256 checksum (below and in `RansomwareSentinel-Setup.exe.sha256`).
  Never turn off Defender or SmartScreen to install it.

### New in 1.3.0

**Automatic protection**
- Desktop, Documents, Downloads, Pictures, Videos and Music are proposed
  automatically and found through Windows itself, so redirected folders are
  found where they really are. OneDrive is detected and offered, but off by
  default because its sync activity can look like ransomware.
- A new Protected Locations page shows every folder and whether it can
  really be watched (watched, covered, missing, no access).
- Start Protection checks your folders, runs a quick initial scan of file
  names (it never opens or changes a file), then starts continuous
  monitoring. Optionally, protection starts whenever Sentinel opens.
- Sentinel's own files are never reported as activity, and nested folders
  are watched once.

**Guided from the first launch**
- A four-step setup wizard: what Sentinel does and doesn't do, your folders,
  the initial scan, and protection active.
- A guided tour that points at the real controls, a "Next step" box on the
  dashboard that always shows the one thing worth doing, a workflow hint on
  every page (Protect › Investigate › Respond › Verify), a Getting Started
  page and short help wherever a term needs explaining.
- The Demo Center's "Presenting it" walkthrough shows the whole workflow
  safely, on synthetic files.

Detection rules, risk scoring and the database are unchanged from 1.2.0.

### Please keep in mind

Ransomware Sentinel watches the folders you choose while it is open. It is
not antivirus and does not replace Microsoft Defender, it does not stop
programs or block file changes, and it cannot decrypt or recover files. It
cannot guarantee that every attack is detected. Use it alongside your
antivirus and regular backups. The [documentation](https://h4timfr.github.io/ransomware-sentinel-site/docs/#limitations)
lists every limitation.
